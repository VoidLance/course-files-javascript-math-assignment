# JavaScript Math Assignment

A small browser-based JavaScript exercise that calculates the sum and mean of a
number list and displays the results on a web page.

## Why this project is useful

This project demonstrates basic JavaScript concepts, including arrays, loops,
functions, arithmetic, rounding, and updating HTML from a script. It is a
lightweight example for practicing introductory programming without installing
dependencies or setting up a build system.

## Get started

1. Download or clone this repository.
2. Open [`index.html`](index.html) in a web browser.
3. The page displays the sum and mean. Open the browser's developer console to
   see the unrounded values logged by the script.

The default data is `[4.2, 5.1, 3.8, 4.7, 5.3]`, so the page displays:

```text
Sum: 23.1
Mean: 4.62
```

To try different values, edit the `data` array in [`script.js`](script.js) and
reload the page. No package manager, dependencies, or build command are
required.
